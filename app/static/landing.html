Complete System Architecture

Built For Complete Data Sovereignty

Every component of SlothClerk is engineered to operate without external network dependencies.

🛡️

100% Airgapped Privacy

Telemetry is completely stripped and disabled. ChromaDB runs on embedded DuckDB/parquet files, and Ollama runs locally on your workstation GPU or CPU.

🎙️

ElevenLabs Executive Voice

Generate spoken audio briefings of red flags and critical deadlines. Integrated with ElevenLabs studio TTS with automated fallback to local browser Web Speech synthesis.

🔍

Verbatim Citation Auditor

Hallucinations are eliminated. Every key date, money amount, obligation, and red flag is mathematically verified against the source text chunk before presentation.

☁️

Render Cloud Ready

Equipped with an automated render.yaml blueprint, containerized Dockerfile, and intelligent fallback for instant cloud web service deployments.

⚡

Deterministic Clause Scanner

Sub-millisecond pattern matching identifies repossession rights, jury trial waivers, automatic renewals, and uncapped liabilities before generative LLM synthesis.

📄

Unified CLI & Web Engine

Audit contracts from your terminal (python cli.py) or through the rich single-page web app. One-click export to Markdown and structured JSON.
